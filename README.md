# 커스텀 로보 GX (GBA) 한글 패치

*Custom Robo GX* (게임보이 어드밴스, 일본판 `ARJJ`) 비공식 한국어 팬 패치입니다.
일본판(『カスタムロボGX』) 원문을 기준으로 번역했고, 1편·V2 한글 패치와 용어·말투를 이어 맞췄습니다.

**제작: arqhive** · **최신 버전: [v1.0f](../../releases/tag/v1.0f)**

- 본편 대사, 선택지, 메뉴, 로보·파츠 설명, 도움말, 아이템 설명, 지도 장소 이름, 대회 정보를 한글화했습니다.
- 타이틀 로고와 대회 카드·표·간판·메뉴 그림 속 글자를 한글화했습니다.
- 주인공 이름을 한글로 입력할 수 있습니다. 이름 뒤 조사(을/를, 이/가 등)는 이름 끝 글자의 받침에 맞춰 자동으로 바뀝니다.
- 원작에서도 영어인 문구는 영어 그대로 두었습니다.
- 배포본은 원본 롬에 적용하는 **BPS 패치**입니다. 롬 크기(8MB)는 그대로입니다.

> 이 저장소에는 **게임 데이터(롬, 추출한 원문 대사, 원본 그래픽, 스크린샷)가 들어 있지 않습니다.**
> 패치를 적용하려면 본인이 소유한 게임에서 직접 덤프한 원본이 필요합니다.

## 사용자용: 패치 적용

### 준비물

- 일본판 롬 파일(`ARJJ`). 북미판·유럽판은 없는 게임입니다.

| 항목 | 패치 전(원본) | 패치 후(v1.0f) |
|---|---|---|
| 크기 | 8,388,608바이트 | 8,388,608바이트 |
| CRC32 | `F533DC13` | `45791FA5` |
| MD5 | `ae35fb67a74c92a3f063408fd0bc4a29` | `1f1be44796c0967f44a6b0140347294d` |
| SHA-256 | `e445679a00f5862ec82a327807b9cb9b72d50608061413987383f8e8c86e8e7a` | `011b18973221431aa477f5addea8ec7bf5f37337cf27567302bb5dc24ba83cd4` |

- BPS 패치를 적용하는 프로그램(Floating IPS, Rom Patcher JS 등).

### 적용 방법

1. [릴리즈 페이지](../../releases/latest)에서 `ARJJ_KPatch_v<버전>.zip`을 받아 압축을 풉니다.
2. 패치 프로그램에서 원본 롬과 `ARJJ_KPatch_v<버전>.bps`를 고르고 적용합니다.
3. 만들어진 롬의 해시가 위 표의 「패치 후」와 같은지 확인하고 실행합니다.

### 실행 환경

- **확인함**: 3DS open_agb_firm, mGBA.
- 3DS open_agb_firm에서는 세이브 종류를 직접 정해 줘야 합니다. 압축 안의 `CustomRoboGX_KO_v<버전>.ini`를 한글판 롬과 같은 이름으로 바꿔 `/3ds/open_agb_firm/saves/` 폴더에 넣으세요.

### 알려진 문제

- 칸이 모자란 곳은 일부 단어를 붙여 썼습니다.
- GBA끼리 하는 통신 대전과 파츠 교환은 실제로 해 보지 못했습니다.

### 비밀번호

레이디 P의 연구실에서 비밀번호를 넣으면 파츠 등을 받을 수 있습니다. 한글 입력 화면에서 띄어쓰기 없이 넣습니다.

| 비밀번호 | 받는 것 |
|---|---|
| 눈의거인 | 빅풋 |
| 지옥의업화 | 헬파이어 |
| 악마의숨결 | 데몬 블레이즈 |
| 비밀의건 | 니카이도 건 |
| 숨겨진봄 | 니카이도 봄 |
| 무시무시한포드 | 니카이도 포드 |
| 챔프의건 | 크로스 시저스 |
| X-레이주세요 | X-레이 |
| 티켓KR2 | 코로코로 컵 참가권 |
| 커스텀로보 | 연습용(선물 없음) |

그 밖에 `커스텀로보V2`, `커스텀로보V3`, `커스텀로보GX`, `노이즈`, `닌텐도`, `레이디P`, `좋아해요`, `로보박사`, `피타로`, `안녕하세요`, `좋은저녁이에요`, `안녕히계세요`, `고마워요`를 넣으면 레이디 P가 대답만 합니다.

금고 비밀번호는 `레이스카이어`입니다.

## 개발자용

- 번역문: [`work/translation/`](work/translation)에 한국어 번역문만 들어 있습니다. `out-id/`는 대사(대사 ID별), `out/raw-*.json`은 메뉴·설명 같은 평문입니다. `{0A}`는 주인공 이름, `{01}`·`{02}`·`{04}`는 글자 색, `{05}`는 줄바꿈, `{07}`·`{08}`은 입력 대기라 그대로 둡니다. `을(를)`·`이(가)`·`은(는)`·`(으)로`·`과(와)`는 이름 뒤 조사 표기입니다.
- 도구: [`tools/`](tools)에 추출·글꼴·빌드·검사·배포 도구 소스가 있습니다(Python 3.13, Pillow, keystone-engine, unicorn).
- 일본어 원문 추출본, 그림 작업 파일, 작업 상태 기록은 게임 데이터이거나 작업용이라 넣지 않았습니다. 그래서 이 저장소만으로는 바로 빌드되지 않고, 원본 롬에서 추출부터 다시 해야 합니다.
